# THE BACKROOMS: ENDLESS

無限に続く「バックルーム」を探索する一人称視点の探索・サバイバルホラー。
画像・音・3Dモデルはすべてプログラムで生成しています(外部アセット不使用)。

- 仕様書: [SPEC_v0.3.md](SPEC_v0.3.md)(§17 にユーザー指示による変更点)
- 進捗: [PROGRESS.md](PROGRESS.md)

## 遊び方

### いちばん簡単(Windows・常に最新版)
Node.js と Git を入れて `git clone` した後、フォルダ内の **`起動.bat` をダブルクリック**。
最新版の取得 → 部品の更新 → ゲームウィンドウで起動 までを自動で行います。

### exe をダウンロードする
1. GitHub の **Actions** タブ → 「build」の最新の実行(緑のチェック)を開く
2. **Artifacts** の `BackroomsEndless-windows` をダウンロードして解凍
3. `BackroomsEndless-x.y.z-portable.exe` をダブルクリック(`-setup.exe` はインストーラ版)

> コード署名をしていないため、初回は Windows SmartScreen の警告が出ます。「詳細情報」→「実行」で起動できます。
> `v*` タグ(例 `v0.1.0`)を push すると GitHub Releases にも exe が添付されます。

### ブラウザ(開発用)
```
npm install
npm run dev
```
http://localhost:5173/ を開く。`?debug=1` でデバッグ表示、`?seed=文字列` でシード固定、`?level=13` で開始レベル指定、`?noworker=1` でワーカーなし。
exe 版の起動引数: `--level=<id>` `--seed=<seed>` `--dev`。

## モード
- **エンドレス**: 無限の世界を自由に探索し、できるだけ多くのレベルを「放浪者の記録」に残す(10/50/100 で節目の演出)
- **脱出モード**: Level 0 → 1 → 2 → 3 → 4 と進み、現実への出口を目指す。どの出口も次のレベルにつながる。たどり着くとエンディング

> はじめての人は `導入.txt`、GitHub アカウントを持っていない人は `導入.md` を参照。

## 開発者モード2(戦闘テスト)
タイトル画面またはポーズ画面(Esc)の「開発者モード2:戦闘テスト」から入れます。
- 四方を壁に囲まれた大きな部屋(52m 四方。柱・低い遮蔽物・高い壁あり)に、全武器と弾を持った状態で入る
- 最初から敵が**常に3体**いるように無限に出てくる(倒すと少しして補充)。数(OFF/1/3/5体)と種類(ランダム/1種類)を変更可
- 敵を選ぶと、向いている方向の指定距離(6/12/20/35m)に手動で出現。ゲーム中は Esc → 開発者モード2 でいつでも追加
- 無敵・弾無限・敵を止める(当たり判定の確認用)を切り替えられる。設定はすぐ反映(無限出現の数・種類を変えると、今いる敵が入れ替わる)
- 「テスト場に入りなおす」で、今の設定のまま最初からやり直せる(敵の出しなおし、武器・体力満タン)
- 画面右上に各エンティティの状態(行動・HP・距離・透明度)を表示
- テスト場にいる間はセーブされず、ジャーナルにも記録されない

## ゲームのしくみ
- ゲージは **体力**(時間で少しずつ減る。アーモンドウォーターで回復。ダッシュも満タンになる)と **ダッシュ** の2本。体力が0になると持ち物の半分を失い、レベルの入口から再開
- アイテム欄は6枠。アーモンドウォーター、武器、弾薬
- **武器**はとてもレア。前の調査隊員の亡骸のそばに落ちている。弾薬はフィールドに落ちている
  - ピストル: 即着弾(ヒットスキャン)、12発、反動なし、距離で威力が落ちる
  - マグナム: 弾が飛ぶ(弾速あり)、6発、撃つと少し上にずれ、次の発射で元に戻る。距離減衰なし
  - クナイ: まっすぐ飛ぶ(70m を過ぎると落ちる)。押しっぱなしで毎秒2本の連射。10本まで。刺さったクナイは近づくと回収できる
  - 斧: 近接
  - ロケットランチャー(とてもレア): 威力150。クナイの0.8倍の速さで飛ぶロケットが爆発し、周りを強く吹き飛ばす。足元や背後の床に撃つと自分が吹き飛んで大ジャンプ・高速移動ができる(自分へのダメージ・その着地の落下ダメージはなし)。1発ずつ装填、拾うと5発
  - 予備弾の上限はすべて999
  - 頭に当てるとダメージ増。右クリックでのぞき込み(ズーム・感度は設定で調整)
- **エンティティ**: スマイラー・ハウンド・ダラー・フェイスリング・スキンスティーラー・フクレ(近くで膨らんで破裂する)・ダイダラ(高さ約6.5mの巨人。踏みつけてくる。空の見えるレベルや天井の高いレベルだけ)・ガンマン(距離を取って横に動きながらマグナムを6連射。弾は見て避けられる)・ウィッチャー(足元に光る輪を出し、1秒ほどで雷を落とす範囲攻撃)・ボマー(山なりに爆弾を投げる。着地して赤く点滅したあと爆発し、吹き飛ばされる)
  - 爆発(フクレの破裂・ボマーの爆弾)はノックバックあり。近くの敵も巻き込んで吹き飛ばす
  - ダイダラ以外は、弾をよけるように左右に揺れながら近づいてくる
  - 頻繁に出る(レベルに入って約10〜20秒後から、12〜32秒おき。同時に最大3体、難しいは4体)。出る前には必ず予兆(明滅・唸り声・字幕)がある
  - 体力は当初の5倍(例: ハウンド 350、スキンスティーラー 750、ダイダラ 3000)
  - 捕まるとダメージを受け、相手は去っていく(フクレは破裂、ダイダラは間をおいて何度も踏みつける)。扉や戻り口の近くには来ない。Level 0 には出ない
- 3D モデルは `public/models/<名前>.glb`(例: `entity_smiler.glb`, `weapon_pistol.glb`)を置くと差し替わる(無ければ手続き生成のモデル)
- 各レベルには独特の構造物(マニラ・ルーム、巨大な像、終わらない階段、水槽の回廊、奈落と橋、太鼓橋 など)があり、入るとジャーナルに記録される

### 別のレベルへの行き方
- **扉**を開ける(非常口、ガラスの引き戸、鉄扉、白い扉、空中に立つ扉 など。鍵のかかった扉もある)
- 少し色の明るい、ゆっくり明滅する**壁**に向かって押し続ける(ノークリップ)
- 少し青みがかった**床**の上に立ち続ける(床が抜ける)。浮遊する場所では**足場から落ちる**
- オレンジ色の**マニラ・ルーム**に留まる、**光の門**(滝の壁、石の環、標識門の下)に入る
- ひたすら遠くまで**歩く**

到着すると背後に光る**戻り口**が現れ、E で元の場所に戻れます(落下などは一方通行)。
同じ出口は何度使っても同じ行き先です。

### レベル
- 手作り: 0 ロビー / 1 居住区 / 2 配管の夢 / 4.3 白い廊下 / 7.5 桟橋 / 13 温室 / 14 非常口の先 / 27 床下 / 37 プールルーム / 139 壁の向こう / U1 天空の高速道路 / U2 畳の橋 / U3 エアロの未来 / The Void
- 広がり方いろいろ: 111 無限螺旋階段(縦)/ 222 無限トンネル(一本道)/ 303 雪山(斜めに登る)/ 666 火山(限られた道)/ 1000 時の神殿(ひと部屋)/ 808 永遠の孤島(漂流物でしか出られない)/ 120 洞窟(縦横)/ 512 無限マンション(縦)/ 77 キノコの湿地 / 451 本の回廊(跳び移る)/ 313 食道(下へ)/ 900 巨像 / NULL 透明な虚無 / 212 夜の屋上 / 9999 終端の浮島 / 37.2 重なるプールルーム / 186 夜の病院 / chaos(崩れた世界)
- それ以外の番号は、番号から決まった世界が自動生成されます(26種の構造 × 空 × 配色 × 構造物)。ときどき名前が文字化けした「バグレベル」に迷い込みます
- Level 0 は遠くまで歩くと、来た道の形が少しずつ変わっていきます(非ユークリッド。設定でオフ可)

## セーブ
ニューゲームでスロット(3つ)とモードを選ぶと、そのスロットに自動でセーブされます(レベル移動時・一定間隔・ポーズ時・終了時)。
タイトル画面の「コンティニュー」で最後のセーブから再開。exe 版は `%APPDATA%/backrooms-endless/saves/` に保存されます。

## 設定
タイトル・ポーズ画面の「設定」から:
- **操作**: マウス感度(X/Y 別)、Y軸反転、FOV、ダッシュ・しゃがみの長押し/トグル、ゲームパッド感度・デッドゾーン
- **キー割り当て**: 全アクションにキー/マウス/ホイール2つ+ゲームパッドのボタン。重複時は入れ替え/上書きを選択
- **映像**: 画面モード、品質、解像度スケール、描画距離、フレームレート上限、垂直同期(exe・再起動後)、明るさ、ガンマ、フィルムグレイン、色収差
- **音**: マスター/環境音/効果音/エンティティ/ハム音
- **ゲーム**: 難易度、字幕、HUD の表示と大きさ、非ユークリッドな迷路、ワールドシード、オートセーブ間隔

### アクセシビリティ
点滅軽減、画面揺れ軽減、ヘッドボブの強さ、字幕(ささやき声・足音・扉の音)、HUD の拡大、明るさ・ガンマ調整。

## 開発者用レベル選択
タイトル・ポーズ画面の「開発者:レベルを選ぶ」から、手作りレベル、生成レベルの各タイプの見本、任意の番号を選んで開始できます。

## 開発
```
npm test             # Vitest(決定性・チャンク境界・50km 移動・出口・セーブ・バランス など)
npm run build        # 型チェック + Vite ビルド
npm run electron     # Electron で起動
npm run dist         # Windows exe(Windows 上で実行)
```
- `src/levels/` レベル定義と生成(純粋関数、テスト可能)。`hand/` 手作り、`procedural/` 生成、`gridPieces.ts` 構造物
- `src/world/` チャンク管理・ジオメトリ(ワーカーで生成)・当たり判定
- `src/systems/` 空、光、音、幻覚、ジャーナル、ポストエフェクト
- `src/ui/` HUD、タイトル/ポーズ、設定、ジャーナル、レベル選択(文言は `ja.json`)
