==============================================================
  THE BACKROOMS: ENDLESS  導入手順(はじめての人向け)
==============================================================

このゲームを Windows のパソコンで遊べるようにするまでの手順です。

基本は「起動.bat で遊ぶ方法」です(この下の【ステップ0】〜【ステップ3】)。
一度準備すれば、起動するたびに自動で最新版になります。

  ・exe をダウンロードして遊ぶ方法もあります。
    → 最後の「コラム:exe で遊ぶ方法」を見てください。
  ・ゲームはデスクトップに置きます。OneDrive の関係でうまくいかない
    ときは「コラム:OneDrive でデスクトップに入れられない場合」へ。
  ・GitHub のアカウントを持っていない人は「導入.md」を見てください。


--------------------------------------------------------------
■ 【ステップ0】始める前に:Windows のブロックを確認する
--------------------------------------------------------------

Windows 11 には「スマート アプリ コントロール」という機能があり、
これが「オン」だと、ゲームやインストーラーが勝手にブロックされて
動かないことがあります。最初に状態を確認してください。

  1. 画面左下のスタートボタン(Windows マーク)を押す
  2. 「Windows セキュリティ」と入力して開く
  3. 左側の「アプリとブラウザー コントロール」を押す
  4. 「スマート アプリ コントロールの設定」を押す
  5. 状態が「オン」「評価」「オフ」のどれになっているか確認する

  ・「オフ」 …… そのまま次へ進んでOK
  ・「評価」 …… たいていはそのまま進めます。途中で何かがブロック
                  されたら、下の「うまくいかないとき」を見てください
  ・「オン」 …… ブロックされる可能性が高いです。
                  ブロックされたら、下の「うまくいかないとき」を見てください

  ※ この画面が見つからない場合(Windows 10 など)は、この機能はありません。
     そのまま次へ進んでください。


--------------------------------------------------------------
■ 【ステップ1】必要なソフトを2つ入れる(最初の1回だけ)
--------------------------------------------------------------

(1) Node.js(ゲームを動かすための部品)

    1. ブラウザ(Edge や Chrome)で次のページを開く
         https://nodejs.org/ja/download

    2. ページの中ほどにある、緑色のボタン
         「Windows インストーラー (.msi)」
       をクリックする
       → 「node-v(数字)-x64.msi」というファイルがダウンロードされる
       (ボタンの文字は時期によって少し違います。「.msi」と書かれた
         緑のボタンを押せばOKです)

    3. ダウンロードしたファイル(画面右上のダウンロード一覧、または
       「ダウンロード」フォルダの中)をダブルクリックして開く

    4. 英語の画面が出るので、次の順に押す
         「Next」
         → 「I accept the terms in the License Agreement」にチェック → 「Next」
         → 「Next」 → 「Next」
         → 「Tools for Native Modules」の画面はチェックを付けずに「Next」
         → 「Install」
         → 「このアプリがデバイスに変更を加えることを許可しますか?」
            と聞かれたら「はい」
         → 「Finish」

(2) Git(ゲームのファイルを取ってきて、更新するための道具)

    1. ブラウザで次のページを開く
         https://git-scm.com/downloads/win

    2. いちばん上の「Click here to download」をクリック
       → 「Git-(数字)-64-bit.exe」がダウンロードされる

    3. ダウンロードしたファイルをダブルクリックして開く
       → 「はい」(変更を許可)

    4. 英語の画面が何枚も出ますが、設定は何も変えずに
       「Next」を押し続け、最後に「Install」→「Finish」

  ※ 2つとも入れ終わったら、パソコンを一度再起動すると確実です。


--------------------------------------------------------------
■ 【ステップ2】ゲームを取ってくる(最初の1回だけ)
--------------------------------------------------------------

  1. 画面左下のスタートボタン(Windows マーク)を押す
  2. 「PowerShell」と入力し、出てきた「Windows PowerShell」をクリック
     (青か黒の、文字を打つ画面が開きます)

  3. 下の4行を「1行ずつ」コピーして、PowerShell の画面で
     右クリック(=貼り付け)→ Enter キー、を繰り返す

       cd ([Environment]::GetFolderPath("Desktop"))

       git clone https://github.com/hirabayashishotaro/backroomsgame.git

       cd backroomsgame

       git checkout claude/quirky-brown-jxx4aj

     ・1行目でデスクトップに移動します
       (「PS C:\Users\(名前)\Desktop>」のように表示されます)
       ★ ここで「OneDrive」という文字が入っていたら
         (例: PS C:\Users\(名前)\OneDrive\デスクトップ>)、
         後ろの「コラム:OneDrive でデスクトップに入れられない場合」を
         先に読んでください
     ・2行目のあと、GitHub のログイン画面が出たらログインして許可する
     ・2行目が終わって、また「PS C:\...>」が出てから3行目を貼る
       (途中で次の行を貼ると、質問への答えとして入力されてしまいます)
     ・終わるとデスクトップに「backroomsgame」フォルダができます

  4. PowerShell の画面は閉じてOK


--------------------------------------------------------------
■ 【ステップ3】遊ぶ(毎回これだけ)
--------------------------------------------------------------

  1. デスクトップの「backroomsgame」フォルダを開く
  2. 中にある「起動.bat」をダブルクリック
     ・青い画面「Windows によって PC が保護されました」が出たら
       「詳細情報」→「実行」を押す
  3. 黒い画面が開き、自動で
       最新版の取得 → 部品の準備 → ゲームの起動
     を行います。
     ・初回だけ数分かかります。2回目からは数十秒です。
  4. ゲームのウィンドウが開いたら「ニューゲーム」で開始

  ※ 黒い画面はゲーム中も閉じないでください(閉じるとゲームも終わります)

  便利ワザ:
    「起動.bat」を右クリック →「その他のオプションを表示」
    →「送る」→「デスクトップ(ショートカットを作成)」
    で、デスクトップから直接起動できます。

■ 操作方法
--------------------------------------------------------------

  WASD ............ 移動
  マウス .......... 視点
  Space ........... ジャンプ
  Shift ........... ダッシュ
  Ctrl / C ........ しゃがむ
  E ............... 拾う / 扉を開ける / 戻り口に入る
  左クリック ...... 攻撃(撃つ・投げる・振る)
  右クリック ...... エイム(のぞき込み)
  R ............... リロード
  Q ............... アーモンドウォーターを飲む
  1〜6 / ホイール . アイテムの持ち替え
  Tab / J ......... 放浪者の記録(訪れたレベルと経路図)
  Esc ............. ポーズ(設定・セーブ・タイトルへ戻る)
  F11 ............. フルスクリーン切り替え

  ※ キー割り当て・マウス感度などは「設定」から変更できます。
  ※ ゲームパッドも使えます。


--------------------------------------------------------------
■ 遊び方のコツ
--------------------------------------------------------------

  ・体力は時間で少しずつ減ります。アーモンドウォーターで回復します
    (ダッシュも満タンになります)。
  ・別のレベルへ行く方法:
      扉を開ける / 少し色が明るく明滅する壁に押し続ける /
      少し青っぽい床に立ち続ける / 光の門に入る / ひたすら遠くへ歩く
  ・着いた先の背後に光る「戻り口」があり、E で元の場所へ戻れます。
  ・武器は、倒れた調査隊員のそばにまれに落ちています。
  ・セーブは自動です(レベル移動時・2分ごと・ポーズ時・終了時)。
  ・「脱出モード」にはエンディングがあります。条件は画面上部に表示されます。
  ・タイトル画面の開発者メニュー:
      開発者:レベルを選ぶ ……… 好きなレベルへすぐ行ける
      開発者モード2 ……………… 敵と武器を試せる戦闘テスト場
      開発者モード3 ……………… エンディングまでの流れを確認できる


--------------------------------------------------------------
■ うまくいかないとき
--------------------------------------------------------------

  Q. 「このアプリはブロックされました」「スマート アプリ コントロールが
     ブロックしました」などと出て、起動.bat・インストーラー・ゲームが動かない
  A. 【ステップ0】の「スマート アプリ コントロール」が原因です。
     ・状態が「評価」なら、しばらく使っていると自動で「オフ」になることが
       あります。急ぐ場合は次の方法で「オフ」にします。
     ・「Windows セキュリティ」→「アプリとブラウザー コントロール」→
       「スマート アプリ コントロールの設定」で「オフ」を選ぶ
     ※ 注意:Windows のバージョンによっては、一度「オフ」にすると
       Windows を入れ直すまで「オン」に戻せません。
       心配な場合は、パソコンに詳しい人に相談してから変えてください。

  Q. 青い画面「Windows によって PC が保護されました」が出る
  A. 「詳細情報」という小さな文字を押すと「実行」ボタンが出ます。
     (署名をしていないファイルなので出る警告です)

  Q. ウイルス対策ソフト(ノートン、ウイルスバスターなど)が止めてしまう
  A. 「backroomsgame」フォルダを、そのソフトの「除外」に追加してください。

  Q. 起動.bat を開くと「Git が見つかりません」「Node.js が見つかりません」
  A. ステップ1のソフトが入っていません。入れたあと、パソコンを再起動。

  Q. PowerShell で「認識されません」と出る
  A. PowerShell を閉じて開き直す。だめならパソコンを再起動。

  Q. cd で「パス … Desktop が存在しないため検出できません」と出る
  A. 古い手順の「cd $HOME\Desktop」を使っています。OneDrive を使っている
     パソコンではデスクトップの場所が違うためです。今の手順の
       cd ([Environment]::GetFolderPath("Desktop"))
     を使ってください。

  Q. git clone で「Deletion of directory ... failed. Should I try again? (y/n)」
     が何度も出る
  A. OneDrive がデスクトップを同期していて、git の邪魔をしています。
     n を押して Enter(止まらなければ Ctrl + C)。
     後ろの「コラム:OneDrive でデスクトップに入れられない場合」を見てください。

  Q. git clone で「Repository not found」と出る
  A. リポジトリが非公開でアクセスできません(持ち主に公開してもらう)。

  Q. git clone で「already exists」と出る
  A. すでに「backroomsgame」フォルダがあります。まず
       cd backroomsgame
       git checkout claude/quirky-brown-jxx4aj
     を試してください。エラーになる場合は、そのフォルダを削除してから
     もう一度ステップ2を実行してください。

  Q. 画面が真っ黒・「起動できませんでした」と出る
  A. グラフィックドライバを最新にしてください。
     それでもだめなら、表示された文字をそのまま教えてください。

  Q. 動きが重い
  A. Esc →「設定」→「映像」で、品質を「低」、描画距離を小さくしてください。

  Q. 起動.bat で「エラー」と出て止まった
  A. 黒い画面に出ている文字を、そのまま貼り付けて教えてください。


--------------------------------------------------------------
■ コラム:OneDrive でデスクトップに入れられない場合
--------------------------------------------------------------

OneDrive を使っているパソコンでは、デスクトップが OneDrive に同期されて
いることがあります。そのままだと git が途中で失敗したり
(「Deletion of directory ... failed」が何度も出る)、
ゲームの部品(数千個のファイル)まで同期されて重くなったりします。
次のどちらかの方法を使ってください。

【方法1】OneDrive の同期を一時停止してから、デスクトップに入れる

  1. 画面右下のタスクバーにある「雲のアイコン」(OneDrive)をクリック
  2. 右上の歯車 →「同期を一時停止」→「2 時間」を選ぶ
  3. デスクトップに途中までできた「backroomsgame」フォルダがあれば削除
  4. PowerShell を開き直して、ステップ2をはじめからやり直す
  ※ 2時間たつと同期が再開します。そのあと動きがおかしくなったら方法2へ。

【方法2】デスクトップの外に入れて、デスクトップにはショートカットを置く
       (いちばん確実です)

  1. デスクトップに途中までできた「backroomsgame」フォルダがあれば削除
  2. PowerShell を開き直し、ステップ2の4行のうち1行目だけを
       cd $HOME
     に変えて実行する(残りの3行は同じ)
     → C:\Users\(あなたの名前)\backroomsgame にフォルダができます
  3. エクスプローラー(黄色いフォルダのアイコン)を開き、上のアドレス欄に
       %USERPROFILE%\backroomsgame
     と入力して Enter → フォルダが開く
  4. 中の「起動.bat」を右クリック →「その他のオプションを表示」
     →「送る」→「デスクトップ(ショートカットを作成)」
  5. これからは、デスクトップのショートカットをダブルクリックすれば遊べます


--------------------------------------------------------------
■ コラム:exe で遊ぶ方法(インストール不要。ただし更新は手動)
--------------------------------------------------------------

Node.js や Git を入れずに、完成品の exe を直接動かす方法もあります。
ただし、新しい版が出るたびにダウンロードし直す必要があり、
スマート アプリ コントロールが「オン」だとブロックされやすい方法です。

  1. ブラウザで次のページを開く(GitHub にログインしておく)
       https://github.com/hirabayashishotaro/backroomsgame/actions

  2. 一覧の一番上にある「緑のチェック ✅」がついた行をクリック
     (黄色い丸は作成中、赤い ✕ は失敗なので選ばない)

  3. 開いたページを下にスクロールし、「Artifacts」欄の
       BackroomsEndless-windows
     をクリック → zip ファイルがダウンロードされる

  4. ダウンロードした zip を右クリック →「すべて展開」

  5. 展開したフォルダの中の
       BackroomsEndless-(数字)-portable.exe
     をダブルクリック

  6. 青い画面「Windows によって PC が保護されました」が出たら
     「詳細情報」→「実行」を押す

  7. タイトル画面が出たら「ニューゲーム」→ スロットを選ぶ → モードを選ぶ
