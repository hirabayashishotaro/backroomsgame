# THE BACKROOMS: ENDLESS

無限に続く「バックルーム」を探索する一人称視点の探索・サバイバルホラー。
すべてのテクスチャ・音はコードで生成しています(外部アセット不使用)。

仕様書: [SPEC_v0.3.md](SPEC_v0.3.md) / 進捗: [PROGRESS.md](PROGRESS.md)

## いちばん簡単な遊び方(Windows・常に最新版)
Node.js と Git を入れて `git clone` した後は、フォルダ内の **`起動.bat` をダブルクリック**するだけです。
自動で「最新版の取得 → 部品の更新 → ゲームウィンドウで起動」を行います。

## 遊び方(ブラウザ・開発用)
```
npm install
npm run dev
```
ブラウザで http://localhost:5173/ を開き、クリックで開始。

- `?debug=1` … デバッグ表示
- `?seed=任意の文字列` … ワールドシード固定
- `?level=0` … 開始レベル

## 操作
| 入力 | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 視点 |
| Space | ジャンプ |
| Shift | ダッシュ |
| Ctrl / C | しゃがむ |
| E | 拾う / 扉を開ける / 戻り口に入る |
| Q / 左クリック | アーモンドウォーターを飲む(体力回復) |
| 1〜4 / ホイール | 持ち替え |
| Esc | ポーズ・設定 |

## モード
- **エンドレス**: 無限の世界を探索し、できるだけ多くのレベルを「放浪者の記録」(Tab)に残す
- **脱出モード**: Level 0 → 1 → 2 → 3 → 4 と進み、現実への出口を目指す(どの出口も次のレベルへ)

## セーブ
ニューゲームでスロット(3つ)を選ぶと、そのスロットに自動でセーブされます(レベル移動時・一定間隔・ポーズ時・終了時)。
タイトル画面の「コンティニュー」で最後のセーブから再開できます。

## 設定
タイトル画面・ポーズ画面(Esc)の「設定」から、操作(マウス感度 XY 別・Y軸反転・FOV・トグル操作)、キー割り当て、
ゲームパッド、映像(画面モード・解像度・描画距離・明るさ など)、音量、難易度・字幕・HUD などを変更できます。変更はすぐ反映・保存されます。

## 開発者用レベル選択
タイトル画面またはポーズ画面(Esc)の「**開発者:レベルを選ぶ**」から、好きなレベルで始められます。
手作りレベル(0 / 1 / 2 / U1 / U2 / U3 / Void)、生成レベルの各タイプの見本(庭園・夜空、浮遊道路、虚無の足場 など)、任意の番号を選べます。

## 別のレベルへの行き方(Level 0)
- 緑の表示灯がついた**非常口**の扉を開ける
- 曇りガラスの**引き戸**を開ける
- オレンジ色の**マニラ・ルーム**にしばらく留まる
- 少し色の明るい、ゆっくり明滅する**壁**に向かって押し続ける(ノークリップ)
- 少し青みがかった**床**の上に立ち続ける(床が抜ける)
- ひたすら遠くまで歩く

着いた先では、背後に光る**戻り口**が現れます。E で元の場所に戻れます。

## exe(Windows)の入手方法
1. GitHub リポジトリの **Actions** タブを開く
2. 「build」ワークフローの最新の実行(緑のチェック)を開く
   - main ブランチ以外で試す場合は「Run workflow」から手動実行できます
3. ページ下部の **Artifacts** から `BackroomsEndless-windows` をダウンロードして解凍
4. `BackroomsEndless-x.y.z-portable.exe` をダブルクリック(インストール不要)。`-setup.exe` はインストーラ版

`v*` タグ(例 `v0.1.0`)を push すると、GitHub Releases にも exe が添付されます。

> **注意**: コード署名をしていないため、初回起動時に Windows SmartScreen の警告が出ます。「詳細情報」→「実行」で起動できます。

exe 版の起動引数: `--level=<id>` `--seed=<seed>` `--dev`(デバッグ表示)。F11 でフルスクリーン切り替え。
設定とセーブは `%APPDATA%/backrooms-endless/` に保存されます。

## 自分の PC でビルドする場合

```
npm run electron   # Electron で起動

```
